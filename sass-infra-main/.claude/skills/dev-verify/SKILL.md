# Step 4: Verify

Review all changed files against the plan to confirm completeness.

## What To Do

1. **Review every planned item** — go through your plan line by line and confirm each change was implemented
2. **Check for missed files** — ensure no files from the plan were accidentally skipped
3. **Verify code compiles** — confirm there are no TypeScript errors or import issues in changed files
4. **Cross-check feature docs** — compare your changes against the relevant feature doc to ensure consistency with existing patterns

## Checklist

- [ ] Every planned item implemented
- [ ] No files from the plan were missed
- [ ] Code compiles without TypeScript errors
- [ ] Changes are consistent with existing patterns in the feature docs
