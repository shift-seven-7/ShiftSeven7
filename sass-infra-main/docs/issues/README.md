# Issues

One markdown file per bug discovered but not fixed, named after the symptom
(kebab-case). Written during step 6 of the workflow, so that finding a bug while
doing something else does not become an unplanned detour.

Format:

```md
# <symptom>

**Found:** <date> while <what you were doing>
**Severity:** low | medium | high

## What happens
## Expected
## Where
## Notes
```
